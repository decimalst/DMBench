Potion miscibility is a DMG variant, not a universal mandatory consequence. If the DM uses it, overlapping potions or potions mixed in a container can call for a d100 roll on its table. Outcomes include adverse interactions, normal operation, and beneficial interactions; a second potion is not automatically harmful. Do not require invented table ranges or assert that every game must roll for every pair. Verify this rubric against the 2014 DMG variant before using it for scored comparisons.
