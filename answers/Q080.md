An ordinary rogue has only one action, so cannot spend it on both Attack and Ready; Cunning Action does not supply either. A rogue/fighter using Action Surge can attack with one action and Ready a bow shot with the additional action. If the trigger occurs on another creature's turn before the rogue's next turn, it can spend its reaction to shoot. Sneak Attack is once per turn, so it can apply to both hits on different turns if each meets its conditions. A readied shot on the rogue's own turn would not allow a second Sneak Attack that turn.
